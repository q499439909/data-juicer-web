# Upstream attribution

Data-Juicer Web is based on [datajuicer/data-juicer-agents](https://github.com/datajuicer/data-juicer-agents), which uses [Data-Juicer](https://github.com/datajuicer/data-juicer) and [AgentScope](https://github.com/agentscope-ai/agentscope).

The original Apache-2.0 LICENSE and upstream copyright notices are retained.
This repository adds the agent_web application, its matching backend changes,
and Web installation, configuration, packaging, documentation, and tests.
It is maintained independently and is not an official upstream release.

The Python distribution keeps the upstream data-juicer-agents package name for
internal compatibility; the GitHub project is data-juicer-web. Upstream documentation,
PyPI publication, and legacy test workflows are retained with a .disabled suffix.
The active workflow is Web deployment checks.
